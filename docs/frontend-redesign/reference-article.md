# 参考文章: AI Agent 交互设计模式 — 要点摘录

> 原文: https://siyujia.net/posts/ai-agent-hci  
> 摘录时间: 2026-08-24  
> 用途: 作为 UI 重构的设计参考

## 核心定位转变

AI Agent 正在从"被动响应用户指令的工具"转变为"能够主动分解任务、调用外部工具、制定执行计划,并在执行过程中进行自我修正的数字劳动力"。

## 三大核心原则

1. **透明化和可解释性**: 让用户清晰看到 Agent 的工作过程和决策依据
2. **认知减负**: 简洁有效地呈现信息,减少干扰、减轻记忆负担
3. **人在环路 (Human-in-the-loop)**: 保证 Agent 工作过程可控、支持用户灵活介入

## 七大关键设计模式

### 模式 1: 注意力引导
- 渐进式展示而非一次性呈现所有信息
- 非高频/重要窗口隐藏折叠
- 信息分层及视觉区分
- 同类元素交互和视觉样式保持一致

### 模式 2: 就地澄清
- 允许用户在任务执行环境中直接反馈和修正
- 提供灵活、定位准确的编辑入口
- 编辑区域与结果预览保持一致性

### 模式 3: 自动建议
- 用选择代替输入,少用开放式提问
- 关键决策点提供数量适当的选项
- 允许用户在选项之外自由输入

### 模式 4: 思考外显
- 让 AI 外显思考过程、计划和决策依据
- AI 工作状态和进度始终清晰可见
- 允许用户调整推理/执行过程展示的详细程度
- 使用思维导图、流程图等可视化手段

### 模式 5: 上下文/知识匹配
- 主动识别相似问题,自动调取历史信息和知识资源
- 标注正在记忆或使用的上下文/知识
- 提供修改或移除自动引用上下文的选项

### 模式 6: 暂停-反馈-继续
- 提供明显的暂停按钮
- 允许中止并保存已完成内容
- 设置关键决策点的自动暂停
- 用户操作可撤销/可逆

### 模式 7: 环境/工作流适配
- 任务启动位置和方式灵活
- 提供多种结果使用方式
- 支持跨平台同步

## 正面案例参考

- **Cursor**: 高亮将对话中的分解步骤与具体代码对应
- **Devin**: "Follow Devin" 窗口,进度条定位到任意步骤
- **Grok**: 纵向进度条展示分解步骤,兼具锚点/导航功能
- **GenSpark**: 文字样式区分对话内容和执行情况,暂停按钮
- **v0**: 实时预览 + 选中界面局部修改
